APNI IMAGES YAHAN RAKHEIN
-------------------------
Website abhi online (Unsplash) images use karti hai. Client ki asli photos lagani hon to:

1. Photo is folder mein copy karein, e.g.  frontend/public/images/haircut.jpg
2. shared/catalog.js kholen aur us service/product ki  image: 'photo-...'  ko   image: '/images/haircut.jpg'  kar den.

Zaroori file:
  payment-qr.png  ->  client ka asli payment QR (JazzCash / Easypaisa / Raast / bank app se download kiya hua).
                      Jab tak ye file nahi rakhi, website demo QR dikhati hai.
